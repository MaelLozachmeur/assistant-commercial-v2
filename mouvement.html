Ce que ces chiffres n'autorisent pas à conclure

Un seul canal : les chiffres reflètent les offres France Travail, pas l'ensemble des recrutements publiés sur d'autres plateformes ou directement par les entreprises. Le schéma OpenAPI France Travail limite chaque page à 150 résultats et le paramètre range à l'index 3149, soit 3 150 résultats par recherche. Si un code ROME dépasse ce seuil, la collecte subdivise récursivement les bornes API minCreationDate/maxCreationDate pour la France entière, jusqu'à la seconde, puis dédoublonne par identifiant. Si plus de 3 150 offres partagent le même instant de création à cette précision, le segment ne peut pas être subdivisé davantage : le code est signalé incomplet et les graphiques restent limités aux offres récupérées. Cette méthode ne découpe pas par département et n'exclut donc pas les offres sans localisation. Le périmètre est une sélection de codes commerciaux pertinents, pas l'ensemble des métiers de vente : il exclut notamment les spécialités de vente au détail et le conseil en information médicale. Une catégorie indiquée « à collecter » n'a pas encore fait l'objet d'une extraction dans le résumé affiché. Les salaires sont ceux des offres qui les affichent, moins d'un tiers : biais probable vers le bas et vers les PME ; le net mensuel est une estimation (brut × 0,78 / 12, avant impôt sur le revenu). Le niveau de poste (assistant·e, chargé·e, responsable, directeur·rice) est déduit de l'intitulé de l'annonce : c'est une approximation, un « chef de projet » n'encadre pas toujours. La formation et la qualification ne sont renseignées que par une minorité d'annonces : les pourcentages qui s'y rapportent portent sur ce petit sous-ensemble, pas sur tout le marché. Les agences d'intérim et de recrutement sont surreprésentées parmi les employeurs et les secteurs : elles publient beaucoup, parfois la même offre plusieurs fois. Plusieurs offres peuvent être publiées par un même employeur ou une agence : un volume d'annonces n'est pas un nombre garanti de postes distincts. Une compétence citée dans une annonce n'est pas nécessairement exigée. La grille de mots-clés est indicative et configurable dans scripts/resumer.py. Un point placé au centre d'une commune ou d'un département n'est pas l'adresse de l'employeur.
